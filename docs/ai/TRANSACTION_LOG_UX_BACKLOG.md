# Haven 交易总表：交互约定与待讨论项

本页记录 2026-09-24 用户明确的产品取舍。交易总表用于按时间回顾收支日志，金额统计由其他模块承担。

## 保留的设计

- 不增加独立表头、日期列或金额排序；保持按时间倒序。
- 商家常显；选择框仅在进入选择模式时显示。
- 自定义日期按钮保持简短，不展开完整日期范围；允许自动纠正起止日期顺序。
- 搜索框失焦自动提交，不增加搜索提交按钮。
- 筛选是次要工具，保留红点提示，不常显筛选条件标签。
- 不常用管理功能继续位于更多菜单。
- 转账通过描述入口单独编辑，不增加批量转账操作。
- 桌面标签继续使用彩色小点和鼠标提示；手机优先录入。
- 本轮不增加交易页显示设置，不改变税收优惠账户统计策略。

## 本轮范围

- 最近 7/14/30 天包含今天，分别从今天减 6/13/29 天开始。
- 转账列表在分页前合并两端；仅一端符合筛选或访问范围时保留该端。不改写账本或核心转账逻辑。
- 总表桌面端列顺序固定为：交易名称、状态、分类、商家、账户、金额；
  状态靠右、分类靠左；交易描述优先，金额列右对齐并保留宽度下限。账户页原布局不变。
- 交易总表只显示交易分类；证券投资活动细节留给规划中的独立投资日志。
- 桌面常显搜索框；移动端空搜索默认折叠，已有搜索词保持可见。
- 金额运算符改为单选；可勾选限定一个原币币种，不勾选时金额条件适用于所有币种，不换汇。
- 概览展开在工具栏下方。
- 总表状态列用同步来源图标表示已关联/同步的交易；普通手动录入不显示保护锁。
  这是来源提示，不改变同步保护、手动编辑保护或详情页解锁行为。

## 验证中发现的既有统计问题（本轮未改）

- 概览按币种金额使用 `Transaction::Search#totals` 中的 `to_i`，会截去小数。
  测试样例：列表支出 USD 1,234,567.89，概览支出及最大支出显示
  USD 1,234,567.00。此问题在本轮改动前的代码中已存在。
  修复属于金融统计准确性工作，应另行增加小数金额回归测试；本轮按用户
  不触碰 Sure 核心计算的要求保留，并明确记录风险。

## 解释记录

- 上次筛选恢复：从导航返回无查询参数的交易页时，会恢复当前会话上次的筛选和分页。这是原有行为，本轮不改变。
- 等宽数字：数字字符宽度一致，有利于逐行比较，不改变字号或行高；本轮未额外启用。
- 币种次要层级：通过字色强调程度实现无需换行；本轮保持现状。
- 拆分分组：全局外观设置控制拆分交易是否聚合展示；不是账户分组或新增统计方式。
